# DropFit Web版 - 项目进度跟踪

## 1. 项目概览

### 1.1 项目目标
将微信小程序"DropFit"重构为GitHub Pages静态网站，专注于CrossFit场馆查找的核心功能。

### 1.2 开发策略
- **移动端优先**：90%使用场景，重点优化手机端体验
- **MVP开发**：先完成核心功能，再迭代优化
- **分阶段交付**：每个阶段都有可运行的版本

### 1.3 技术选型
- **前端**：HTML5 + TailwindCSS + JavaScript ES6+
- **地图**：高德地图API（初期）→ Leaflet（后期）
- **部署**：GitHub Pages
